# Личный сайт Айрата Садыкова

Адрес: https://a1rrat.github.io/

## Публикация

GitHub Pages публикует папку `docs/` из ветки `main`. Сборка и зависимости не нужны. Изменения в `main` автоматически обновляют сайт.

В `docs/` находится персональная страница с опытом, проектами и контактами. Стили, изображения и шрифты хранятся локально; лицензии шрифтов лежат в `docs/assets/fonts/`. Индексация разрешена.

Для обновления изменить HTML и ресурсы в `docs/`, проверить локально и отправить коммит в `main`. Результат деплоя проверять в Actions → pages build and deployment и по публичному адресу сайта.

## Локальный просмотр

Запустить из корня проекта `python -m http.server 8768 --bind 127.0.0.1 --directory docs` и открыть http://127.0.0.1:8768/. Остановить сервер сочетанием Ctrl+C.

## Материалы

На хостинг отправляется только папка `docs/`. Временные выгрузки и материалы исследования хранить в `tmp/` или `private/`: эти каталоги исключены из Git. Перед каждым коммитом проверять список добавленных файлов.

## Свой домен

После выбора домена добавить его в Settings → Pages → Custom domain и настроить DNS по инструкции GitHub. Пока файл `CNAME` не нужен.
